Test user-to-user conversation isolation
Now we'll verify an important security rule:

A Sales Executive must not be able to retrieve the Administrator's conversations.

We'll use your existing Sales Executive account:
- Email: sales@demo-electronics.local
- Role: Staff
Test 1 – Login as Sales Executive
Send:

POST 
http://localhost:5000/api/auth/login

Body:
{
  "email": "sales@demo-electronics.local",
  "password": "Demo@12345"
}

{
  "success": true,
  "message": "Login successful",
  "user": {

SELECT
    full_name,
    email,
    is_active,
    password_hash IS NOT NULL AS has_password
FROM auth_users_biz_agent
WHERE email = 'sales@demo-electronics.local';
