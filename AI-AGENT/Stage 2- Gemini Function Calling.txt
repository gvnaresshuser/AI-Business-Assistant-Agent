Create the first agent tool – getSalesSummary.


Now we have all three essential pieces:
1. Tool declaration – tells Gemini what functions are available.
2. Tool executor – executes only approved backend functions.
3. Sales Summary tool – retrieves actual PostgreSQL figures.


Understand the important flow
Step	What happens
1	User asks a question
2	Gemini decides whether a tool is required
3	Backend receives the function request
4	Tool Executor runs the approved function
5	PostgreSQL returns actual data
6	Backend sends the result to Gemini
7	Gemini generates a natural-language answer

The loop allows Gemini to request a tool and then use its result to formulate the final answer.

What should happen internally?
1. Gemini recognizes that this question requires sales data.
2. Gemini requests getSalesSummary.
3. Our Function Executor calls the approved sales summary function.
4. The function queries sales_orders_biz_agent in NeonDB.
5. The actual database figures are sent back to Gemini.
6. Gemini explains the results in natural language.
