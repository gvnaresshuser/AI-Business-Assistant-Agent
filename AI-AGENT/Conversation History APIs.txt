Archive conversation
Now let's implement the ability to archive completed conversations without deleting their messages.

The intended behaviour:
1. Change session status from Active to Archived.
2. Set ended_at to the current timestamp.
3. Preserve all conversation messages.
4. Exclude archived sessions from the active conversation list (we'll update the listing query accordingly).

Conversation deletion
One final conversation-management feature is useful: deleting an unwanted conversation.

My recommendation is to implement permanent deletion with ownership validation, deleting its associated messages first and then the session. We should use a database transaction so that partial deletion cannot occur.

We'll also test it using an empty test session, not your November Sales Analysis conversation.
