Create a transaction utility

Create a new file:

backend/src/utils/dbTransaction.ts

How it works
BEGIN – Start transaction


Execute database operations


COMMIT
All operations succeed

ROLLBACK
Any operation fails



For example, when deleting a conversation:
1. Delete its messages.
2. Delete its session.
3. Commit both operations together.
If either deletion fails, both are rolled back.
