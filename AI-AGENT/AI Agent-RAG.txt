How does your AI Agent work?
Your AI Agent acts like an intelligent business assistant that understands user questions and performs business operations using predefined tools.
Workflow:
1. User asks a question, for example: "Show me this month's sales."
2. React frontend sends the question to the Node.js/Express backend.
3. Gemini understands the question and determines which tool is required.
4. The backend executes the predefined tool.
5. The tool retrieves business data from PostgreSQL.
6. Gemini prepares a human-readable response.
7. React displays the answer.
Example:

User: "Which are my top five selling products?"
- Gemini identifies the sales-related tool.
- Backend executes the tool.
- PostgreSQL retrieves the top five products.
- Gemini explains the results.

2. How does RAG work?
RAG stands for Retrieval-Augmented Generation.

It allows your AI Assistant to answer questions using your own uploaded business documents.


Workflow:

Document upload process
1. Admin uploads business information as text.
2. Backend splits the text into smaller chunks.
3. Gemini converts each chunk into numerical embeddings.
4. PostgreSQL with pgvector stores the chunks and embeddings.
Question-answering process
1. User asks: "What is the warranty period for Dell laptops?"
2. Gemini converts the question into an embedding.
3. PostgreSQL searches for similar document chunks.
4. Relevant chunks are sent to Gemini as context.
5. Gemini generates an answer based on the retrieved documents.
6. The application displays the answer and relevant sources.
