Regenerate AI Response

Next: Regenerate AI Response
Let's add a Regenerate button beside Copy.

When clicked, it will:
1. Re-submit the original user question.
2. Generate a fresh AI response.
3. Replace the previous assistant response.
4. Preserve the conversation history.
This will consume additional Gemini tokens each time it is used.

How Regenerate will work
1. Retrieve the selected conversation history.
2. Identify the most recent user question and previous AI response.
3. Send the original question to Gemini with the appropriate conversation history.
4. Update the existing assistant message with the new answer.
5. Refresh the frontend response.
